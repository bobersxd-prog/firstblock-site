How it works

Manual payment, local execution.

FirstBlock is distributed as a local desktop app. You keep control of the burner wallet, OpenSea API key, and RPC endpoint. The license only unlocks access.

Wallet safety

Use burner wallets only.

Never use your main wallet. FirstBlock is built for local execution, but NFT minting is risky. Keep only the amount needed for gas and mint price in the wallet you use.

FAQ

Before you buy.

Does FirstBlock guarantee a mint?

No. Supply, gas, RPC speed, OpenSea availability, and contract rules can still make a mint fail.

Do I need an OpenSea API key?

Yes for the AUTO SeaDrop flow. The app uses it to request transaction data from OpenSea.

Should I use my main wallet?

No. Use a burner wallet only.
