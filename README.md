# FirstBlock Site

Static marketing page for FirstBlock.

## Local Preview

Open `index.html` in a browser, or run:

```powershell
npx serve .
```

## Deploy on Vercel

Create a new Vercel project and select this folder as the project root:

```txt
firstblock-site
```

No build command is required for the static version.
